# Unit 2 — Then and Now

A standalone Grade 5 English learning app about technology in the past and today. It includes vocabulary practice, grammar activities, reading, writing workshops, listening support, and a quiz.

## Run locally

Open `index.html` in a modern browser. The app has no build step, server, or third-party runtime dependencies.

## Publish with GitHub Pages

1. Create a **public** GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings > Pages** and set the build and deployment source to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the Actions tab). The workflow deploys the site; its public URL appears in the workflow run and Pages settings.

Students can open the published URL without signing in. There is no student account system or cloud sync. Progress is saved in browser storage on each student's device and is not shared between devices.
